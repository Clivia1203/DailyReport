# 02 — 范围聚焦与范围芯片（互斥模型）

**What to build:** 点击统计卡后列表聚焦到对应日期范围（今日卡→今天、本周卡→本周、累计卡→清除日期筛选），列表顶部出现范围芯片（如"本周 ×"）；点芯片 × 或再点同一张卡取消聚焦。范围聚焦与年/月下拉互斥：激活聚焦时下拉复位为"全部"，改下拉时芯片自动摘除（ADR-0003）；关键词搜索与两者均叠加生效。范围筛选的数据逻辑收口进统计模块并有测试。

**Blocked by:** 01 — 统计条（三卡 + 数据地基）

**Status:** ready-for-agent

- [ ] 点击"今日/本周"卡，列表只剩对应范围的记录且芯片正确显示
- [ ] 点击"累计"卡，清除日期筛选回到全量
- [ ] 点芯片 × 或再点同一张卡可取消聚焦
- [ ] 聚焦激活时改年/月下拉 → 芯片消失、下拉生效；反之激活聚焦 → 下拉复位"全部"
- [ ] 搜索词与任何筛选状态正确叠加（含"day 聚焦+搜索"计数测试）
- [ ] 互斥与叠加逻辑在统计模块测试中覆盖
