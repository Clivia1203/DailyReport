# 日报随手记

一个本地运行的桌面小工具：随手记录每天的工作内容，之后按日期范围一键导出日报。

## 启动

```bash
npm start
```

启动后程序常驻系统托盘（右下角图标），主窗口关闭只是隐藏到托盘，从托盘右键菜单选择"退出"才会真正退出。

## 日常使用

| 操作 | 方式 |
|------|------|
| 快速记录一条 | 任何界面按 **Alt+Shift+D**（可在设置中修改），或单击托盘图标，弹出输入条，输入后回车即保存，时间自动取当前 |
| 补录 / 指定时间 | 主界面录入区可手动修改日期时间；不改动时每 30 秒自动跟随当前时间，"此刻"按钮立即校准 |
| 回顾历史 | 主界面按天分组倒序展示，支持**按年份 / 月份筛选**和**关键词搜索** |
| 编辑 / 删除 | 悬停记录可编辑 ✏️ 或删除 🗑（单条删除可撤销） |
| 批量管理 | 列表右上角"管理"进入批量模式：勾选、全选、删除选中（两段式确认防误删） |
| 导出日报 | 导出区选择开始/结束日期和格式（Markdown / Excel 表格 / 纯文本），生成按天分节的日报文件 |
| AI 周期总结 | 配置自己的 DeepSeek API Key 后，按日报 / 周报 / 月报 / 自定义周期生成总结；支持实时显示思考过程、Markdown / 纯文本显示、编辑、复制和导出 |
| 深浅主题 | 设置页可选"跟随系统 / 浅色 / 深色"，主题按钮不占用主界面常驻位置 |

## 设置（顶栏 ⚙️）

- **快捷键**：点"修改"后直接按下新组合键（需含 Ctrl/Alt/Shift 至少一个修饰键），自动检测格式与系统级冲突，被占用会提示并保留原键
- **主题**：跟随系统 / 浅色 / 深色三选，所有窗口（含快速记录条、标题栏）同步切换
- **开机自启**：默认关闭；开启后写入 Windows 启动项，登录即驻留托盘
- **AI 服务**：填写自己的 DeepSeek API Key，默认掩码显示并可用眼睛按钮临时查看；可重复测试连接刷新模型列表并切换模型，模型下线或更新后生成前会自动重新读取
- **总结模板**：分别配置日报、周报、月报和自定义周期的模板。模板只控制总结结构和表达方式，系统会额外要求保留全部原始记录
- **数据**：显示数据文件路径，一键打开所在文件夹

## 数据说明

- 记录与设置保存在本地：`%APPDATA%\日报随手记\` 下的 `data.json` 与 `settings.json`，可直接备份、拷贝到别的电脑
- DeepSeek API Key 使用 Windows 安全存储加密后写入 `settings.json`，设置页默认只显示掩码；只有用户主动点击眼睛时才临时读取明文
- AI 总结会保留原始记录明细；每次生成前刷新可用模型列表，生成结果按周期、模板、记录内容和模型缓存
- AI 总结使用流式响应，生成期间默认显示简洁进度、当前分段、续写次数和计时；详细思考过程可手动展开，遇到单次输出上限会自动续写，长周期会按完整记录分段生成并合并
- AI 总结正文超过一定大小时会单独保存为 Markdown 文件，避免大报告反复重写数据文件；原始记录明细始终保留，若连接中断也会保存已收到的部分结果
- 思考过程只用于生成期间展示，不写入总结正文、缓存或导出文件
- 未配置 AI 时不联网；配置 DeepSeek 后仅在测试连接或生成总结时按需联网，无后台服务
- 快捷键默认值定义在 `main.js` 顶部的 `DEFAULT_HOTKEY`

## 目录结构

```
├── src/
│   ├── main.js          主进程：托盘、全局快捷键、设置、数据读写、导出
│   ├── preload.js       渲染进程与主进程的安全桥接
│   ├── renderer/        界面（index = 主界面+设置，quick = 快速记录条）
│   └── assets/          应用图标
├── docs/                工程技能配置（跟踪器/标签/领域文档规则）
├── .scratch/            本地票单与 spec（按功能分目录，由工程流程生成）
└── package.json
```
