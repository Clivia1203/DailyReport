# 日报随手记

一个本地运行的桌面小工具：随手记录每天的工作内容，之后按日期范围一键导出日报。

## 启动

```bash
npm start
```

启动后程序常驻系统托盘（右下角图标），主窗口关闭只是隐藏到托盘，从托盘右键菜单选择"退出"才会真正退出。

## 日常使用

| 操作 | 方式 |
|------|------|
| 快速记录一条 | 任何界面按 **Alt+Shift+D**（可在设置中修改），或单击托盘图标，弹出输入条，输入后回车即保存，时间自动取当前 |
| 补录 / 指定时间 | 主界面录入区可手动修改日期时间；不改动时每 30 秒自动跟随当前时间，"此刻"按钮立即校准 |
| 回顾历史 | 主界面按天分组倒序展示，支持**按年份 / 月份筛选**和**本地模糊搜索**（忽略大小写、空格、标点，支持多个关键词） |
| 保存筛选 | 将当前年月、关键词或日期聚焦保存为命名筛选，下次可直接加载；最多保存 20 个 |
| 工作量热力图 | 列表上方显示近 26 周、周一至周日的记录量；点击方块可聚焦到对应日期 |
| 编辑 / 删除 | 悬停记录可编辑 ✏️ 或删除 🗑（单条删除可撤销） |
| 批量管理 | 列表右上角"管理"进入批量模式：勾选、全选、删除选中（两段式确认防误删） |
| 导出日报 | 导出区选择开始/结束日期和格式（Markdown / Excel 表格 / 纯文本），生成按天分节的日报文件 |
| AI 周期总结 | 配置自己的 DeepSeek API Key 后，按日报 / 周报 / 月报 / 自定义周期生成总结；支持实时显示思考过程、Markdown / 纯文本显示、编辑、复制和导出 |
| 近期总结 | 仅在宽屏侧栏显示；独立使用闭环模型，把历史记录中提到过的事项与当前周期的完成结果做对照，不把缺失记录当成未完成 |
| 深浅主题 | 设置页可选"跟随系统 / 浅色 / 深色"，主题按钮不占用主界面常驻位置 |
| 多语言 | 安装器可选择简体中文 / English / 日本語，默认简体中文；安装后也可在设置中切换，主界面和快速记录条同步更新 |

## 设置（顶栏 ⚙️）

- **快捷键**：点"修改"后直接按下新组合键（需含 Ctrl/Alt/Shift 至少一个修饰键），自动检测格式与系统级冲突，被占用会提示并保留原键
- **主题**：跟随系统 / 浅色 / 深色三选，所有窗口（含快速记录条、标题栏）同步切换
- **语言**：安装时默认选择简体中文，也可在设置中切换简体中文、English 或日本語；切换后窗口自动重新加载，历史数据和 AI 输出不变
- **开机自启**：默认关闭；开启后写入 Windows 启动项，登录即驻留托盘
- **AI 服务**：填写自己的 DeepSeek API Key，默认掩码显示并可用眼睛按钮临时查看；可重复测试连接刷新模型列表并切换模型。周期报告和近期闭环分别选择模型、思考强度（自动 / 快速 / 标准 / 深度），两者调用互不混用
- **总结模板**：分别配置日报、周报、月报和自定义周期的模板。模板只控制总结结构和表达方式，系统会额外要求保留全部原始记录
- **近期闭环提示词**：独立于周期报告模板，可修改并保存；如果效果不理想可随时恢复内置默认提示词。修改后不会自动调用 AI，下一次查看或更新闭环时生效
- **AI 设置**：普通设置与 AI 设置分离；AI 设置提供左侧项目导航，分别管理 API Key、周期报告、近期总结和术语规范。首次连接 AI 后自动读取全部日报，识别规范名称和常用说法并合并到词典；用户可以在已有词典上方直接新增或编辑术语，也可以通过支持多关键词和模糊匹配的本地搜索快速定位、编辑或删除；还可以手动“重新识别并合并”，修改或恢复术语识别提示词，不增加快速记录时的字段
- **数据**：显示数据文件路径，一键打开所在文件夹；可导出完整备份或从备份恢复

## 数据说明

- 记录与设置保存在本地：`%APPDATA%\日报随手记\` 下的 `data.json`、`settings.json` 和 `reports/` 正文目录。跨设备迁移或长期留档建议使用设置页的“导出备份”，不要只复制 `data.json`
- 完整备份是一个 JSON 配置文件，包含日报、周期总结、近期闭环、提示词、术语、总结模板和保存的筛选条件；恢复前会自动在 `backups/` 下保留一份安全备份，API Key 永远不会写入备份文件
- DeepSeek API Key 使用 Windows 安全存储加密后写入 `settings.json`，设置页默认只显示掩码；只有用户主动点击眼睛时才临时读取明文
- AI 总结会保留原始记录明细；生成结果按周期、模板、术语词典和原始记录内容的 SHA-256 指纹缓存，模型只记录在报告元数据中，切换模型不会让旧报告消失；重新进入总结页会恢复上次查看的周期，记录、模板或术语变化时保留上次报告并提示重新生成
- AI 总结使用流式响应，生成期间默认显示简洁进度、当前分段、续写次数和计时；详细思考过程可手动展开，遇到单次输出上限会自动续写，长周期会按完整记录分段生成并合并。思考强度“自动”对普通报告使用快速强度，对长周期分段使用标准强度；手动选择后仅改变下一次生成请求
- AI 总结正文超过一定大小时会单独保存为 Markdown 文件，避免大报告反复重写数据文件；原始记录明细始终保留，若连接中断也会保存已收到的部分结果
- 思考过程只用于生成期间展示，不写入总结正文、缓存或导出文件
- 近期闭环首次生成或重新生成时，会把当前周期记录全部带入，并将历史记录按批次对照；结果按周期、记录内容、术语和闭环提示词的 SHA-256 指纹缓存。记录、术语或提示词变化时保留旧结果并标记“待更新”，不会自动重复调用 AI
- 未配置 AI 时不联网；配置 DeepSeek 后仅在测试连接、首次识别术语或按需生成总结时联网，无后台服务；术语识别使用独立的近期闭环模型和思考强度
- 快捷键默认值定义在 `main.js` 顶部的 `DEFAULT_HOTKEY`

## 目录结构

```
├── src/
│   ├── main.js          主进程：托盘、全局快捷键、设置、数据读写、导出
│   ├── preload.js       渲染进程与主进程的安全桥接
│   ├── renderer/        界面（index = 主界面+设置，quick = 快速记录条）
│   └── assets/          应用图标
├── docs/                工程技能配置（跟踪器/标签/领域文档规则）
├── .scratch/            本地票单与 spec（按功能分目录，由工程流程生成）
└── package.json
```
